# Starter СР-2

Реализуйте TODO в пакетах `service` и `repository`. Публичные имена и сигнатуры
менять нельзя: их использует преподавательский набор тестов.

```bash
go test ./...
go test -cover ./...
gofmt -w .
```


## Описание работы

`model` от других пакетов не зависит. тут определена структура заказа.

`service` зависит от `model.Order`. тут описана бизнес-логика валидации и расчёта стоимости доставки.

`repository` зависит от `service` (?). тут определена логика поиска тарифа доставки, определённого в `service` по его строковому представлению.

Покрытие тестами пакета `service` составляет `82%`.

## Наблюдение

Если бы нужно было что-то понять, я бы перенёс описание тарифов в `model`, ошибки вынес бы в отдельный пакет с ошибками, а в `service` оставил бы только `Calculator`.
Тогда `repository` зависел бы только от `model`.
